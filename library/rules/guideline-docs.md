# Writing in .guidelines

Source: regency `library/conventions.md` §7 and §10, `library/virtualpath.md` §3. The project's own documents win.

- State the present, never the correction: text that said "this is A" becomes "this is B", it does not gain
  "no longer A". Remove what no longer matches; version control is the record.
- The index points, it never copies. A fact in two places means one of them is wrong.
- Documents before code: a rule changes in its norm document first, then the code.
- An agent measures, proposes and refuses; it never ratifies a norm it wrote. Cite the Regent's decision with
  its date, and the reason in the Regent's own words when one was given.
- Acts are never rewritten: ladder plans, gate sheets, opinions, closed Orders and dated handoffs. Add a new
  one instead.
- Update the guidelines at the end of each task and list which documents moved. Keep the work ledger
  (`.shortcuts/.virtual/ongoing.json`) true: agents write `review`, never `done`.

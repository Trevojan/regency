# Shortcuts — the entry index and its store

Decision record R7 (`REGENCY_CUSTOMIZATION.md`). Engine: `scripts/shortcuts.py`. Lineage and the work
ledger stay in `scripts/vp.py` (`library/virtualpath.md`); the two scripts never merge.

## 1. Two layers, two scripts

| Layer | Holds | Engine |
|---|---|---|
| `.shortcuts/README.md` | the entry index: where I am, the five-line map, the lookup table, the generated state block | `shortcuts.py` |
| `.shortcuts/.virtual/shortcuts.db` | fingerprints of files and nodes; what changed since the last look | `shortcuts.py` |
| `.shortcuts/.virtual/manifest*.json` | norm slice ↔ code lineage | `vp.py` |
| `.shortcuts/.virtual/ongoing.json` | the work ledger | `vp.py` |
| `.shortcuts/.virtual/checkpoints.jsonl` | the journal | `hook-journal.py` |

## 2. What each part costs and what it buys

| Part | Cost | Buys |
|---|---|---|
| `check` | low: reads the index and the guideline docs | dead pointers, dead anchors, a map past five lines, copied prose and a stale state block are found before a cold agent follows them |
| `drift` | low: a stat per file, a hash only when size or mtime moved | files changed outside the hooks (hand edits, pulls, other tools), named down to the node |
| `refresh` | moderate: git, ledger, journal, a STALE scan | the state lines of the index stop being written by hand (F4) |
| `peek` | low | the first read on resume: the index whole, the live state, the counts, one call |
| `index` / `record` | serious to build, cheap to run | node-level fingerprints: exact per-node change, the base for exact STALE per node (`virtualpath.md` §6) |

## 3. The store

`<guidelines>/.shortcuts/.virtual/shortcuts.db`, SQLite, **gitignored** (`.virtual/.gitignore`, written by
the script). It is a cache: any clone rebuilds it with `shortcuts.py index`. Raw and exact, written for
the harness, not for reading.

| Table | Row | Columns |
|---|---|---|
| `files` | one fingerprinted file | `path` (repo-relative), `sha256`, `bytes`, `mtime_ns`, `prev_sha256` (what the last change replaced), `at`, `session`, `source` (`hook`, `lineage`, `scan`, `refresh`, `manual`, `import`) |
| `nodes` | one heading or Glyph block of a guideline doc | `id` (`<doc>#<anchor>`, the virtual-path form), `doc`, `key`, `kind`, `level`, `parent`, `ord` (document order), `line_start`, `line_end`, `sha256` of the node's **own** lines, `prev_sha256`, `at` |
| `meta` | one fact about the store | `schema` (2), `migrated_from`, `migrated_at`, `migrate_error` |

Rules:

- **Identity is the anchor, never the ordinal.** A node id is the exact anchor `vp.py` resolves (the
  `§name`, else the whole heading text). A repeated heading gets `~2` and `check` reports it, because a
  citation reaches the first one only.
- **A node hashes its own lines**, up to the next heading of any level. A change in a child section never
  moves its parent or siblings.
- **Order is a column.** `before(a, b)` is `a.ord < b.ord` within one doc: an order query, not a search.
- **The prefilter trusts size + mtime.** An edit that keeps both is invisible to `drift` until the next
  `record` or a full `index`; that is the price of not hashing every file on every look.
- **`fingerprints.json` (schema 1) is upgraded, not dropped.** Its rows are imported once into `files`
  with `source = import` and `mtime_ns = -1`, so the next look re-hashes them. The JSON file is left in
  place; removing it from the repository is the Regent's act.
- **`export`** prints the store as JSON (schema 2) for reading and diffing.

## 4. The entry index

`.shortcuts/README.md` is still the one document read whole. `check` holds it to the rules the
guidelines template already states:

| Rule | Source | `check` reports |
|---|---|---|
| the index points, it never copies | conventions §7 | `copy`: a line of 60+ characters found verbatim in another guideline doc |
| every pointer resolves | layouts §1 | `dead`: a link or backticked path that exists under none of the index folder, the guidelines root, the repository |
| every anchor resolves | virtualpath §2 | `anchor`: `path#anchor` naming no node; a repeated heading in the index |
| the map is five lines | `orders/resume.xml` | `map`: the section titled *Map* / *Mapa* past five lines |
| generated text is never hand-edited | F4 | `state`: block missing, markers broken, or content different from a fresh render |

### The generated state block

```text
<!-- shortcuts:state · generated by shortcuts.py refresh; never edit by hand -->
| state | value |
|---|---|
| branch | plumbing |
| version | 2.3 |
| ledger | 1 ongoing / 1 review / 1 blocked / 2 backlog (updated 2026-10-26) |
| ongoing | M01.S01.T01 splitter → mutation round |
| review | … |
| blocked | M01.S02.T01 ← RGN |
| last checkpoint | 2026-10-26T11:40:02-03:00 Edit src/Board.cs (M01.S01.T01) |
| STALE | 1 |
| latest Order | ORD-0003 |
<!-- /shortcuts:state -->
```

Deterministic: no clock and no commit hash (committing the block would change the hash it shows).
`refresh` writes only between the markers, keeps the file's line endings, writes nothing when the
block is current, and records its own write so it never reads as drift. Without markers it writes
nothing; `refresh --init` appends the block once. `hook-acts-guard.py` denies a hand edit inside it.

**When it is written:** at every handoff (`order:handoff` runs `refresh`) and at every session end
(`SessionEnd` → `refresh --hook`). The second one makes the tracked index change once per session in
which the state moved; that is accepted (R7.3).

## 5. Triggers (hooks are triggers, scripts are engines — R4.1)

| Event | Script | Calls |
|---|---|---|
| `PostToolUse` Edit/Write | `hook-lineage.py` | `shortcuts.record()` for the file; again for a norm doc it wrote a STALE line into |
| `PreToolUse` Edit/Write | `hook-acts-guard.py` | `shortcuts.guard_generated()`: deny a hand edit of the state block |
| `SessionStart` | `hook-resume.py` | `shortcuts.summary_part()`: `shortcuts check N · drift N` in the resume line |
| `SessionEnd` | `shortcuts.py refresh --hook` | silent, adoption-gated, never fails; fits the 1.5 s budget (no hashing) |

## 6. Operating

| Need | Command |
|---|---|
| first read on resume | `python scripts/shortcuts.py peek` |
| is the index honest? | `python scripts/shortcuts.py check` (exit 1 on a problem) |
| what changed outside the hooks? | `python scripts/shortcuts.py drift` (exit 1 on drift) |
| bring the store up to date | `python scripts/shortcuts.py index` |
| rewrite the state block | `python scripts/shortcuts.py refresh` (`--init` once) |
| import the old JSON | `python scripts/shortcuts.py migrate` (also automatic on first open) |
| the store as JSON | `python scripts/shortcuts.py export` |
| health | `python scripts/shortcuts.py --selftest` (doctor runs it) |

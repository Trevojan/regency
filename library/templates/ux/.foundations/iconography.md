# Iconography

Files and where they live: `../.assets/README.md`.

- **Product mark:** ⟨path⟩, used as a luminance mask filled with `accent` in the title bar, so it reads
  on both themes. Keep its proportions (⟨w : h⟩). No mark yet: the product name in `title` style.
- **No pictogram set.** The rail uses three-letter mono mnemonics (`../BRIEF.md`, Views).
- **State marks are text characters**, one meaning each:

| Mark | Means |
|---|---|
| ■ | fix |
| ◆ | ask |
| ● | note · issued |
| ✓ | ok |
| ○ | draft |
| ↻ | reissued |
| ⚑ | pin |
| − / + | removed / added line |

- A new mark is added here first, never reuses one, and never replaces the word beside it.
- Format icons, if the product has them, appear only beside their format's label and keep their own
  colours: ⟨list, or "none"⟩.
